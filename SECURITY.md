# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests or discussions.

Report them privately instead:

- **GitHub:** use **Report a vulnerability** on this repository's **Security** tab. Maintainers can turn this on under
  Settings → Code security → Private vulnerability reporting.
- **Or** contact the maintainers directly through the project's official channels.

Please include the affected file or contract, the commit or deployment, what can happen and how, and a suggested fix if
you have one. Do not include private keys or other secrets in a report.
